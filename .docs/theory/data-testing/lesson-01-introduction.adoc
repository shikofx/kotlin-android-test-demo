[[section-what-is-integration-testing]]
== Что такое Интеграционное Тестирование Баз Данных?

Интеграционное тестирование базы данных — это процесс проверки взаимодействия между вашим кодом (например, Data Access Objects - DAO) и самой базой данных. В отличие от *модульных тестов*, которые проверяют отдельные компоненты в полной изоляции (часто с использованием моков), интеграционные тесты фокусируются на том, как эти компоненты работают вместе.

В контексте Android-приложений и библиотеки Room, интеграционные тесты позволяют убедиться, что:

*   Ваши DAO-методы корректно взаимодействуют с Room.
*   SQL-запросы, генерируемые Room на основе ваших аннотаций, выполняются правильно.
*   Данные корректно сохраняются, извлекаются, обновляются и удаляются.
*   Сложные запросы (с сортировкой, фильтрацией, джойнами) возвращают ожидаемые результаты.

[[section-why-it-is-important]]
== Почему это важно?

Хотя модульные тесты очень важны, они не могут полностью гарантировать корректность работы с базой данных. Мокирование DAO в модульных тестах лишь проверяет, что *ваш код вызывает DAO*, но не то, что *DAO действительно работает с базой данных* так, как ожидается.

Интеграционные тесты заполняют этот пробел, предоставляя уверенность в том, что слой данных вашего приложения функционирует правильно. Они помогают выявить ошибки в SQL-запросах, схеме базы данных, преобразователях типов (Type Converters) и других аспектах взаимодействия с БД.

[[section-tools-overview]]
== Обзор Инструментов

Для написания интеграционных тестов с Android Room мы будем использовать следующие ключевые инструменты:

*   **JUnit 5**: Современный фреймворк для написания тестов.
*   **AndroidX Test**: Набор библиотек для тестирования Android-приложений, предоставляющий `ApplicationProvider` для доступа к контексту.
*   **Room Persistence Library**: Сама библиотека Room, включая ее тестовые утилиты (`room-testing`).
*   **Google Truth** (опционально): Библиотека для написания более читаемых и выразительных ассертов.
*   **`InstantExecutorExtension`**: Кастомное расширение JUnit 5 для синхронной работы с `LiveData` в тестах.
