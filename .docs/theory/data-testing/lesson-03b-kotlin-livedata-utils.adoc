== Идиоматичные утилиты для LiveData на Kotlin

Вместо статического Java-метода `getValue`, мы можем создать более элегантное решение с использованием функций-расширений (extension functions) в Kotlin. Это сделает наш тестовый код еще более чистым и читаемым.

=== Функция-расширение `getOrAwaitValue`

Создадим файл `LiveDataTestUtil.kt` и добавим в него функцию-расширение для класса `LiveData`.

```kotlin
// d:/t366/code/sdet-practice/kotlin-android-test-demo/app/src/androidTest/java/com/example/app/utils/LiveDataTestUtil.kt
package com.example.app.utils // Замените на ваш пакет

import androidx.lifecycle.LiveData
import androidx.lifecycle.Observer
import java.util.concurrent.CountDownLatch
import java.util.concurrent.TimeUnit
import java.util.concurrent.TimeoutException

fun <T> LiveData<T>.getOrAwaitValue(
    time: Long = 2,
    timeUnit: TimeUnit = TimeUnit.SECONDS,
    afterObserve: () -> Unit = {}
): T {
    var data: T? = null
    val latch = CountDownLatch(1)
    val observer = Observer<T> { value ->
        data = value
        latch.countDown()
    }
    this.observeForever(observer)

    try {
        afterObserve.invoke()
        if (!latch.await(time, timeUnit)) {
            this.removeObserver(observer)
            throw TimeoutException("LiveData value was never set.")
        }
    } finally {
        this.removeObserver(observer)
    }

    @Suppress("UNCHECKED_CAST")
    return data as T
}
```

=== Как это использовать

Теперь в тестах мы можем вызывать этот метод прямо у объекта `LiveData`, что выглядит очень лаконично:

```kotlin
// Внутри тестового метода
val products = appDao.getAllProducts().getOrAwaitValue()
assertThat(products).isNotEmpty()
```

Эта функция-расширение инкапсулирует всю логику ожидания и делает код тестов максимально сфорованным на бизнес-логике.
