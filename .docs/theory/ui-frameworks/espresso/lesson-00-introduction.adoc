== Что такое Espresso?

**Espresso** (`androidx.test.espresso:espresso-core`) — это основной фреймворк для написания UI-тестов в Android. Он является частью набора AndroidX Test и предоставляет простой и мощный API для взаимодействия с UI вашего приложения.

Ключевая особенность Espresso — **автоматическая синхронизация**. Он ждет, пока UI-поток будет свободен и не будет ожидающих асинхронных задач, прежде чем выполнить следующее действие или проверку. Это избавляет от необходимости писать `Thread.sleep()` и делает тесты более стабильными.

[[section-espresso-core-api]]
== Основное API Espresso: "Триада"

Тест на Espresso обычно состоит из трех частей, которые вместе образуют одну инструкцию:

[source,java]
----
onView(ViewMatcher).perform(ViewAction).check(ViewAssertion)
----

1.  **`onView(ViewMatcher)`**: Находит элемент (`View`) на экране.
    *   `ViewMatcher` — это условие для поиска.

2.  **`.perform(ViewAction)`**: Выполняет действие над найденным элементом.
    *   `ViewAction` — это само действие.

3.  **`.check(ViewAssertion)`**: Проверяет состояние элемента.
    *   `ViewAssertion` — это проверка (ассерт).

=== Пример

[source,java]
----
@Test
fun loginButton_isClickable_andLeadsToNextScreen() {
    // 1. Найти кнопку по ID
    onView(withId(R.id.login_button))
        // 2. Выполнить клик
        .perform(click())
        // 3. Проверить, что на экране появился элемент со следующего экрана
        .check(matches(isDisplayed()))
}
----

В следующих уроках мы детально разберем каждую из этих трех частей, а также рассмотрим более сложные компоненты Espresso.
