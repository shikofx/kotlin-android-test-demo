[[section-what-is-kaspresso]]
== Что такое Kaspresso?

**Kaspresso** — это мощный фреймворк для UI-тестирования на Android, разработанный командой Касперского. Он построен поверх Espresso и UI Automator, но значительно расширяет их возможности, предоставляя комплексное решение для создания стабильных, читаемых и функциональных тестов.

Если Espresso — это низкоуровневый инструмент, а Kakao — это DSL-обертка для повышения читаемости, то Kaspresso — это полноценный фреймворк, который решает множество проблем, с которыми сталкиваются автоматизаторы в реальных проектах:

*   **Нестабильность (Flakiness):** Тесты падают случайным образом из-за проблем синхронизации, анимаций, медленной загрузки данных.
*   **Сложность:** Написание сложных сценариев, включающих работу с системными диалогами, разрешениями, ADB-командами.
*   **Отчетность:** Отсутствие детальных отчетов, скриншотов и видеозаписей для отладки.
*   **Читаемость:** Громоздкий код тестов, который трудно поддерживать.

[[section-kaspresso-philosophy]]
== Философия Kaspresso: "Don't write flaky tests"

Основная идея Kaspresso — помочь разработчикам и тестировщикам писать тесты, которые не падают без причины. Для этого Kaspresso включает в себя:

*   **Автоматические повторные попытки (Retries):** Если элемент не найден или действие не выполнилось с первой попытки, Kaspresso автоматически повторяет попытку несколько раз, ожидая стабилизации UI.
*   **Улучшенная синхронизация:** Расширяет механизмы синхронизации Espresso, позволяя более надежно дожидаться завершения асинхронных операций.
*   **Мощный DSL:** Предоставляет чистый и выразительный Kotlin DSL для описания UI-взаимодействий.
*   **Интеграция с системными возможностями:** Позволяет управлять разрешениями, сетью, выполнять ADB-команды прямо из теста.
*   **Богатая отчетность:** Автоматически генерирует скриншоты, видеозаписи и подробные логи для Allure Report.

[[section-key-advantages]]
== Ключевые преимущества Kaspresso

1.  **Стабильность:** Встроенные механизмы повторных попыток и ожидания значительно снижают количество "флаки" тестов.
2.  **Читаемость:** Чистый Kotlin DSL делает тесты похожими на описание пользовательских сценариев.
3.  **Функциональность:** Поддержка ADB-команд, разрешений, UI Automator, работа с системными диалогами.
4.  **Отчетность:** Автоматическая генерация скриншотов, видео и подробных отчетов (Allure).
5.  **Расширяемость:** Возможность кастомизации поведения через `Interceptors`.

[[section-setup]]
== Настройка Kaspresso

Для начала добавьте необходимые зависимости в ваш `build.gradle.kts` (модуля `app`):

```kotlin
dependencies {
    // Kaspresso core
    androidTestImplementation("com.kaspersky.android-components:kaspresso:1.6.0") // Уточните последнюю версию

    // Если используете Allure Report
    androidTestImplementation("com.kaspersky.android-components:kaspresso-allure-support:1.6.0")

    // Для работы с UI Automator (если нужны межприложенные тесты)
    androidTestImplementation("androidx.test.uiautomator:uiautomator:2.3.0")
}
```

В следующем уроке мы рассмотрим основные строительные блоки Kaspresso: `KTestCase`, `KScreen` и `KView`.
