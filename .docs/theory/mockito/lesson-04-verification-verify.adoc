**Верификация** — это процесс проверки того, что методы мока были вызваны так, как мы ожидали. В Mockito это делается с помощью функции `verify`.

[[section-basic-verification]]
== Базовая верификация

По умолчанию `verify` проверяет, что метод был вызван **ровно один раз**.

```kotlin
import org.mockito.kotlin.verify

@Test
fun `test basic verification`() {
    // Act
    repository.getProducts()

    // Assert
    verify(repository).getProducts()
}
```

[[section-verifying-call-count]]
== Проверка количества вызовов

Вы можете точно указать, сколько раз должен был быть вызван метод, используя `times()`, `atLeast()`, `atMost()` и т.д.

```kotlin
import org.mockito.Mockito.times
import org.mockito.Mockito.atLeastOnce
import org.mockito.Mockito.never

// Проверить, что метод был вызван ровно 2 раза
verify(repository, times(2)).doSomething()

// Проверить, что метод был вызван как минимум 1 раз
verify(repository, atLeastOnce()).doSomething()

// Проверить, что метод не был вызван ни разу
verify(repository, never()).doSomethingElse()
```

[[section-verifying-order]]
== Проверка порядка вызовов

Для проверки порядка вызовов используется объект `InOrder`.

```kotlin
val inOrder = Mockito.inOrder(repository)

// Проверяем, что сначала был вызван stepOne(), а затем stepTwo()
inOrder.verify(repository).stepOne()
inOrder.verify(repository).stepTwo()
```
