**Стабинг** — это процесс "обучения" мока, то есть определения того, что он должен делать при вызове его методов. В Mockito это делается с помощью конструкции `when(...).thenReturn(...)`.

Библиотека `mockito-kotlin` предоставляет более удобный синоним — `whenever`.

[[section-basic-stubbing]]
== Базовый стабинг с `thenReturn`

```kotlin
import org.mockito.kotlin.whenever

@Test
fun `test basic stub`() {
    // Arrange
    val mockProducts = listOf(Product(1, "Test Product", 10.0, 1))
    val liveData = MutableLiveData(mockProducts)

    // "Обучаем" мок: "когда будет вызван метод repository.getProducts(), верни liveData"
    whenever(repository.getProducts()).thenReturn(liveData)

    // Act
    val result = repository.getProducts()

    // Assert
    result.getOrAwaitValue() shouldBe mockProducts
}
```

[[section-advanced-stubbing]]
== Продвинутые техники стабинга

=== Выброс исключения (`thenThrow`)

```kotlin
whenever(repository.getProducts()).thenThrow(RuntimeException("Database error"))
```

=== Возврат разных значений при последовательных вызовах

```kotlin
// Первый вызов вернет product1, второй и последующие - product2
whenever(repository.getProduct(1)).thenReturn(product1, product2)
```

=== Для `void` методов (`doNothing`, `doThrow`)

Для методов, которые ничего не возвращают, используется другой синтаксис.

```kotlin
import org.mockito.kotlin.doNothing
import org.mockito.kotlin.doThrow

// Указать, что метод не должен ничего делать
doNothing().whenever(repository).clearCache()

// Указать, что метод должен выбросить исключение
doThrow(RuntimeException()).whenever(repository).clearCache()
```
