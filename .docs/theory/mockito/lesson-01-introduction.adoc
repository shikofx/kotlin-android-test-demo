[[section-what-is-appium]]
== Что такое Appium?

**Appium** — это open-source фреймворк для автоматизации нативных, мобильных веб- и гибридных приложений. Он позволяет писать тесты для iOS, Android и других платформ, используя один и тот же API.

Ключевая особенность Appium — его **клиент-серверная архитектура**. Ваши тесты (клиент) отправляют команды на Appium-сервер, который, в свою очередь, транслирует их в команды, понятные для конкретной платформы (например, используя **UiAutomator2** для Android).

[[section-appium-vs-espresso]]
== Appium vs Espresso/Kaspresso

Это самое важное различие, которое нужно понимать.

*   **Espresso/Kaspresso (White-box/Gray-box):**
    *   Работают *внутри* процесса вашего приложения.
    *   Имеют доступ к коду и ресурсам приложения.
    *   Очень быстрые и стабильные.
    *   Ограничены рамками вашего приложения.
    *   Тесты пишутся на Kotlin/Java.

*   **Appium (Black-box):**
    *   Работает *вне* процесса вашего приложения, как реальный пользователь.
    *   Не имеет доступа к коду приложения, взаимодействует только через UI.
    *   Может взаимодействовать с системным UI (уведомления, настройки) и другими приложениями.
    *   Тесты можно писать на любом языке (Kotlin, Java, Python, JavaScript, C# и др.).
    *   Медленнее и потенциально менее стабилен из-за сетевых задержек между клиентом и сервером.

[[section-when-to-use-appium]]
== Когда использовать Appium?

*   Когда нужно тестировать сценарии, выходящие за рамки одного приложения (например, "сделать фото в камере и прикрепить его в нашем приложении").
*   Когда тестовая команда отделена от команды разработки и не имеет доступа к исходному коду.
*   Когда тесты нужно писать на языке, отличном от Kotlin/Java.
*   Для проведения истинного "black-box" тестирования, имитирующего действия пользователя без знания внутренней реализации.
