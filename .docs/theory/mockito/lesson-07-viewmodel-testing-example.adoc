[[section-viewmodel-test]]
== Тест для `ProductCatalogViewModel`

```kotlin
import androidx.lifecycle.MutableLiveData
import com.example.app.data.DatabaseRepository
import com.example.app.data.Product
import com.example.app.ui.product_catalog.ProductCatalogViewModel
import com.example.app.utils.InstantExecutorExtension
import com.example.app.utils.getOrAwaitValue
import com.google.common.truth.Truth.assertThat
import org.junit.jupiter.api.BeforeEach
import org.junit.jupiter.api.Test
import org.junit.jupiter.api.extension.ExtendWith
import org.mockito.Mock
import org.mockito.junit.jupiter.MockitoExtension
import org.mockito.kotlin.verify
import org.mockito.kotlin.whenever

@ExtendWith(MockitoExtension::class, InstantExecutorExtension::class)
class ProductCatalogViewModelTest {

    @Mock
    private lateinit var repository: DatabaseRepository

    private lateinit var viewModel: ProductCatalogViewModel

    @BeforeEach
    fun setUp() {
        viewModel = ProductCatalogViewModel(repository)
    }

    @Test
    fun `loadProducts should call repository and update LiveData`() {
        // 1. Arrange (Подготовка)
        val mockProducts = listOf(Product(1, "Mock Product", 99.9, 1))
        val liveData = MutableLiveData(mockProducts)
        whenever(repository.getProducts()).thenReturn(liveData)

        // 2. Act (Действие)
        viewModel.loadProducts()

        // 3. Assert (Проверка)
        val products = viewModel.products.getOrAwaitValue()
        assertThat(products).isEqualTo(mockProducts)

        verify(repository).getProducts()
    }
}
```

=== Что здесь происходит?

1.  **`@ExtendWith(MockitoExtension::class, ...)`**: `MockitoExtension` инициализирует поля, аннотированные `@Mock`.
2.  **`@Mock`**: Аннотация, которая помечает поле как мок, который нужно создать.
3.  **`whenever(repository.getProducts()).thenReturn(liveData)`**: С помощью функции-обертки из `mockito-kotlin` мы настраиваем мок. Говорим ему, что при вызове `getProducts()` он должен вернуть наш тестовый `LiveData`.
4.  **`viewModel.loadProducts()`**: Вызываем тестируемый метод.
5.  **`assertThat(products).isEqualTo(mockProducts)`**: Проверяем, что `ViewModel` корректно выставила данные, полученные от репозитория.
6.  **`verify(repository).getProducts()`**: Убеждаемся, что `ViewModel` действительно вызвала нужный метод у репозитория.

Этот тест полностью идентичен по своей логике тесту с MockK, но использует синтаксис Mockito. Это хорошо показывает, что, зная принципы, можно работать с любым из этих фреймворков.
