Часто нам не важно, с каким именно значением был вызван метод, или мы хотим проверить только часть аргументов. Для этого используются **матчеры аргументов**.

[[section-argument-matchers]]
== Матчеры аргументов

Библиотека `mockito-kotlin` предоставляет удобные синонимы для стандартных матчеров Mockito.

*   `any()`: Любое значение указанного типа.
*   `eq(value)`: Значение, равное `value`.
*   `anyOrNull()`: Любое значение, включая `null`.

```kotlin
import org.mockito.kotlin.any
import org.mockito.kotlin.eq

@Test
fun `test with argument matchers`() {
    // Стабинг: когда getProduct вызывается с любым Int, вернуть product1
    whenever(repository.getProduct(any())).thenReturn(MutableLiveData(product1))

    // Верификация: проверить, что метод insertProduct был вызван с любым объектом Product
    verify(repository).insertProduct(any())

    // Верификация: проверить, что метод getProduct был вызван со значением 1
    verify(repository).getProduct(eq(1))
}
```

[[section-capturing-arguments]]
== Захват аргументов (`ArgumentCaptor`)

Иногда нужно выполнить сложные проверки над аргументом, который был передан в мок. Для этого используется `ArgumentCaptor`.

```kotlin
val captor = argumentCaptor<Product>()

// Верифицируем вызов и одновременно указываем, что нужно захватить аргумент
verify(repository).insertProduct(captor.capture())

// Теперь мы можем выполнять проверки над захваченным значением
val capturedProduct = captor.firstValue
capturedProduct.name shouldStartWith "Test"
```
