[[section-what-is-fragment-scenario]]
== Что такое `FragmentScenario`?

В современных Android-приложениях часто используется подход Single-Activity, где большая часть UI представлена `Fragment`'ами. Тестировать каждый фрагмент, запуская целую `Activity`, может быть медленно и избыточно.

`FragmentScenario` из библиотеки `androidx.fragment:fragment-testing` решает эту проблему. Он позволяет запускать и тестировать `Fragment` в изоляции, без необходимости создавать и настраивать хост-`Activity`.

[[section-using-fragment-scenario]]
== Использование `FragmentScenario`

`FragmentScenario` запускает ваш фрагмент внутри пустой, специально созданной `Activity` и позволяет управлять его жизненным циклом.

=== Пример теста

Давайте напишем тест для `LoginFragment`, который проверяет, что поле для ввода логина отображается на экране.

```kotlin
import androidx.fragment.app.testing.launchFragmentInContainer
import androidx.test.espresso.Espresso.onView
import androidx.test.espresso.assertion.ViewAssertions.matches
import androidx.test.espresso.matcher.ViewMatchers.isDisplayed
import androidx.test.espresso.matcher.ViewMatchers.withId
import androidx.test.ext.junit.runners.AndroidJUnit4
import com.example.app.R // Замените на ваш пакет
import com.example.app.ui.LoginFragment // Замените на ваш пакет
import org.junit.Test
import org.junit.runner.RunWith

@RunWith(AndroidJUnit4::class)
class LoginFragmentTest {

    @Test
    fun usernameField_isDisplayed() {
        // Запускаем LoginFragment в контейнере
        launchFragmentInContainer<LoginFragment>(themeResId = R.style.AppTheme)

        // Проверяем, что поле для ввода имени пользователя видимо
        onView(withId(R.id.username_input)).check(matches(isDisplayed()))
    }
}
```

*   `launchFragmentInContainer<LoginFragment>()`: Это основной метод. Он создает и запускает экземпляр `LoginFragment`.
*   `themeResId`: Важно указать тему вашего приложения, иначе фрагмент может отобразиться некорректно (например, с неправильными цветами или размерами текста).

Использование `FragmentScenario` — это лучший способ писать быстрые, надежные и изолированные UI-тесты для ваших фрагментов.
