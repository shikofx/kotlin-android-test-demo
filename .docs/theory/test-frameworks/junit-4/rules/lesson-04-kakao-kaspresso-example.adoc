Фреймворки-обертки, такие как Kakao и Kaspresso, не заменяют механизм правил. Они используют его "под капотом" для подготовки тестового окружения.

[[section-kakao-example]]
== Пример с Kakao

Тест на Kakao использует те же самые аннотации `@RunWith` и `@Rule`. Меняется только тело самого теста, которое становится более читаемым благодаря DSL Kakao.

```kotlin
import androidx.test.ext.junit.rules.ActivityScenarioRule
import androidx.test.ext.junit.runners.AndroidJUnit4
import com.agoda.kakao.screen.Screen.Companion.onScreen
import com.example.app.ui.login.LoginActivity
import org.junit.Rule
import org.junit.Test
import org.junit.runner.RunWith

@RunWith(AndroidJUnit4::class)
class LoginKakaoTest {

    @get:Rule
    var activityRule = ActivityScenarioRule(LoginActivity::class.java)

    @Test
    fun successfulLogin_opensProductCatalog() {
        onScreen<LoginScreen> {
            usernameField.typeText("standard_user")
            passwordField.typeText("secret_sauce")
            loginButton.click()
        }
        onScreen<ProductCatalogScreen> {
            title.isDisplayed()
        }
    }
}
```

[[section-kaspresso-example]]
== Пример с Kaspresso

Kaspresso идет еще дальше и предоставляет свой базовый класс `KTestCase`, который упрощает настройку. Однако он по-прежнему полностью совместим с правилами JUnit 4.

```kotlin
import androidx.test.ext.junit.rules.ActivityScenarioRule
import com.kaspersky.kaspresso.testcases.api.testcase.TestCase
import com.example.app.ui.login.LoginActivity
import org.junit.Rule
import org.junit.Test

class LoginKaspressoTest : TestCase() {

    @get:Rule
    var activityRule = ActivityScenarioRule(LoginActivity::class.java)

    @Test
    fun successfulLogin_opensProductCatalog() = run {
        step("Login with valid credentials") {
            LoginScreen {
                usernameField.typeText("standard_user")
                passwordField.typeText("secret_sauce")
                loginButton.click()
            }
        }
        step("Verify product catalog is opened") {
            ProductCatalogScreen {
                title.isDisplayed()
            }
        }
    }
}
```

**Вывод:** Независимо от того, используете ли вы чистый Espresso, Kakao или Kaspresso, `ActivityScenarioRule` остается фундаментальным инструментом для запуска `Activity` в ваших UI-тестах.
