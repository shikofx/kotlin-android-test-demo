Иногда возникает необходимость инкапсулировать повторяющуюся логику `setup`/`teardown` в собственное правило. Для этого нужно реализовать интерфейс `TestRule`.

[[section-custom-rule-example]]
== Пример: Правило для логирования времени выполнения теста

Давайте создадим простое правило, которое будет логировать имя каждого теста и время его выполнения.

```kotlin
import android.util.Log
import org.junit.rules.TestRule
import org.junit.runner.Description
import org.junit.runners.model.Statement

class LoggingTestRule : TestRule {
    override fun apply(base: Statement, description: Description): Statement {
        return object : Statement() {
            override fun evaluate() {
                val startTime = System.currentTimeMillis()
                Log.d("LoggingTestRule", "Starting test: ${description.methodName}")

                try {
                    base.evaluate() // Здесь выполняется сам тест
                } finally {
                    val duration = System.currentTimeMillis() - startTime
                    Log.d("LoggingTestRule", "Finished test: ${description.methodName} in $duration ms")
                }
            }
        }
    }
}
```

*   **`TestRule`**: Интерфейс, который нужно реализовать.
*   **`apply(base: Statement, description: Description)`**: Основной метод. `base` — это объект, представляющий сам тест. `description` содержит метаданные о тесте (имя класса, имя метода).
*   **`return object : Statement() { ... }`**: Мы возвращаем новый `Statement`, который "оборачивает" исходный.
*   **`base.evaluate()`**: Этот вызов запускает выполнение самого теста. Код до него — это аналог `@Before`, код после (в блоке `finally`) — аналог `@After`.

=== Использование

```kotlin
class MyFeatureTest {
    @get:Rule
    val loggingRule = LoggingTestRule()

    @Test
    fun mySlowTest() {
        Thread.sleep(1000)
    }
}
```

При запуске этого теста в Logcat вы увидите сообщения о начале и завершении теста с указанием времени выполнения. Это демонстрирует, как правила могут инкапсулировать сквозную функциональность для ваших тестов.
