[[section-what-is-kakao]]
== Что такое Kakao?

**Kakao** — это библиотека для Android UI-тестирования, написанная на Kotlin. Она не заменяет Espresso, а является его **умной оберткой (DSL - Domain Specific Language)**. Kakao берет на себя всю мощь Espresso, но предоставляет более читаемый, лаконичный и структурированный API, который идеально ложится на идиомы языка Kotlin.

Если Espresso — это набор строительных блоков (`onView`, `perform`, `check`), то Kakao — это готовый архитектурный паттерн (Page Object), реализованный с помощью этих блоков.

[[section-why-kakao-is-better]]
== Почему Kakao лучше, чем чистый Espresso?

В курсе по Espresso мы рассмотрели паттерн "Robot" (Page Object) как лучшую практику. Kakao формализует и автоматизирует этот паттерн.

*   **Читаемость:** Тесты на Kakao читаются почти как обычный текст. Сравните:

    *Espresso (с паттерном Robot):*
    `loginRobot.typeUsername("user")`
    `loginRobot.clickLoginButton()`

    *Kakao:*
    `onScreen<LoginScreen> { usernameField.typeText("user") }`
    `onScreen<LoginScreen> { loginButton.click() }`

*   **Структура:** Kakao заставляет вас следовать паттерну Page Object, создавая классы-экраны (`Screen`). Это предотвращает написание "грязных" тестов, где логика и детали реализации смешаны.

*   **Меньше кода:** Kakao предоставляет готовые компоненты для всех стандартных View (`KButton`, `KTextView`, `KRecyclerView`), что избавляет от необходимости писать повторяющийся код для поиска элементов.

[[section-core-concepts]]
== Основные концепции Kakao

1.  **Screen:** Класс, который представляет один экран вашего приложения. Он содержит все UI-элементы этого экрана. Это и есть реализация Page Object.
2.  **KView:** "Умный" представитель любого `View` на экране (`KButton`, `KEditText` и т.д.). Он знает, как с собой взаимодействовать (`click`, `typeText`) и как проверять свое состояние (`isVisible`, `hasText`).
