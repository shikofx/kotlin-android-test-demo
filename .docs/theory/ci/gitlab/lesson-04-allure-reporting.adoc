Стандартные отчеты о тестах часто бывают недостаточно информативными. **Allure Framework** — это инструмент, который позволяет создавать красивые, интерактивные и очень подробные отчеты о выполнении тестов.

[[section-allure-features]]
== Возможности Allure

*   Группировка тестов по функциональности, фичам, эпикам.
*   Добавление шагов, описаний, ссылок на задачи в Jira.
*   Прикрепление скриншотов, логов, видео и других файлов к тестам.
*   Наглядная статистика и графики.

[[section-allure-integration]]
== Интеграция с `pytest` и GitLab CI

Интеграция Allure состоит из двух шагов:
1.  **Сбор результатов:** Во время тестового прогона генерируются JSON-файлы с результатами.
2.  **Генерация отчета:** Утилита Allure Commandline обрабатывает эти JSON-файлы и создает HTML-отчет.

=== Пример задачи в `.gitlab-ci.yml`

```yaml
test_and_report_job:
  stage: test
  script:
    # Запускаем тесты (например, pytest), которые генерируют Allure-результаты
    - pytest --alluredir=allure-results

    # Устанавливаем Allure Commandline и генерируем отчет
    - apt-get update && apt-get install -y allure
    - allure generate allure-results --clean -o allure-report

  artifacts:
    when: always # Сохранять артефакты, даже если задача упала
    paths:
      - allure-report
    expire_in: 1 week
```

[[section-gitlab-pages]]
== Публикация отчета с помощью GitLab Pages

Чтобы не скачивать отчет каждый раз, его можно автоматически опубликовать на статическом сайте с помощью **GitLab Pages**. Для этого создается специальная задача `pages`.

```yaml
pages:
  stage: deploy
  script:
    # Копируем сгенерированный отчет в директорию public
    - mv allure-report public
  artifacts:
    paths:
      - public
```

После выполнения этого пайплайна ваш Allure-отчет будет доступен по адресу вида `https://<your-username>.gitlab.io/<project-name>`.
