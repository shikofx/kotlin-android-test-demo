== Что такое Desired Capabilities?

**Desired Capabilities** — это набор пар "ключ-значение", которые клиент (ваш тест) отправляет на Appium-сервер для конфигурации тестовой сессии. В Python они обычно представляются в виде словаря (`dict`).

=== Основные Capabilities для Android:

*   `platformName`: "Android"
*   `appium:platformVersion`: Версия Android (например, "13.0").
*   `appium:deviceName`: Имя устройства (например, "Android Emulator" или UDID реального устройства).
*   `appium:automationName`: Имя драйвера. Для Android это всегда "UiAutomator2".
*   `appium:app`: Путь к вашему `.apk` файлу.

[[section-pytest-fixture]]
== Управление драйвером с помощью фикстур `pytest`

В `pytest` для управления `setup` и `teardown` логикой (подготовка и очистка) используются **фикстуры**. Это идеальный механизм для управления жизненным циклом драйвера.

Создадим файл `conftest.py` в корне нашего тестового проекта. `pytest` автоматически находит этот файл и делает фикстуры из него доступными для всех тестов.

```python
# conftest.py

import pytest
from appium import webdriver
from appium.options.android import UiAutomator2Options

@pytest.fixture(scope="function")
def driver():
    # 1. Описываем Capabilities
    options = UiAutomator2Options()
    options.platform_name = "Android"
    options.device_name = "emulator-5554"  # Замените на ваше устройство
    options.app = "/path/to/your/app.apk"  # Укажите путь к вашему APK

    # 2. Инициализируем драйвер
    appium_server_url = "http://127.0.0.1:4723"
    app_driver = webdriver.Remote(appium_server_url, options=options)

    # 3. Передаем драйвер в тест
    yield app_driver

    # 4. Код после 'yield' выполняется после завершения теста
    app_driver.quit()
```

=== Что здесь происходит?

1.  **`@pytest.fixture`**: Декоратор, который помечает функцию `driver()` как фикстуру.
2.  **`scope="function"`**: Указывает, что эта фикстура будет создаваться и уничтожаться для *каждой тестовой функции*. Это обеспечивает изоляцию тестов.
3.  **`UiAutomator2Options`**: Современный и рекомендуемый способ задания capabilities.
4.  **`yield app_driver`**: Ключевое слово `yield` передает управление (и созданный `app_driver`) в тестовую функцию.
5.  **`app_driver.quit()`**: Код после `yield` выполняется после того, как тест завершился. Здесь мы корректно завершаем сессию.

Теперь любой тест, который принимает аргумент с именем `driver`, автоматически получит от `pytest` готовый к работе драйвер.
