**Фикстуры** — это самая мощная и важная концепция в `pytest`. Они позволяют отделить подготовку теста (Arrange) от его выполнения (Act) и проверки (Assert).

[[section-what-are-fixtures]]
== Что такое фикстура?

Фикстура — это функция, помеченная декоратором `@pytest.fixture`, которая подготавливает и предоставляет данные, объекты или ресурсы для тестов. Тесты получают доступ к фикстуре, просто указав ее имя в качестве аргумента.

Фикстуры решают две основные задачи:
1.  **Внедрение зависимостей (Dependency Injection):** Предоставляют тестам готовые объекты (например, экземпляр драйвера, подключение к БД).
2.  **Setup/Teardown:** Выполняют код до и после теста (например, запуск и остановка драйвера).

[[section-driver-fixture]]
== Пример: Фикстура для Appium-драйвера

Давайте еще раз посмотрим на фикстуру для управления Appium-драйвером, которую мы создавали ранее.

```python
# conftest.py

import pytest
from appium import webdriver
from appium.options.android import UiAutomator2Options

@pytest.fixture(scope="function")
def driver():
    # --- Код до теста (Setup) ---
    options = UiAutomator2Options().load_capabilities(...)
    app_driver = webdriver.Remote("http://127.0.0.1:4723", options=options)

    # Передаем драйвер в тест
    yield app_driver

    # --- Код после теста (Teardown) ---
    app_driver.quit()
```

*   **`@pytest.fixture`**: Помечает функцию как фикстуру.
*   **`yield app_driver`**: Ключевое слово `yield` разделяет `setup` и `teardown` части. Все, что до `yield`, выполняется перед тестом. Затем выполняется сам тест. После завершения теста выполняется код, который идет после `yield`.
*   **`scope="function"`**: Определяет жизненный цикл фикстуры.
    *   `function`: Фикстура создается и уничтожается для *каждой тестовой функции* (поведение по умолчанию). Идеально для изоляции тестов.
    *   `class`: Фикстура создается один раз для всего тестового класса.
    *   `module`: Фикстура создается один раз для всех тестов в файле.
    *   `session`: Фикстура создается один раз на всю тестовую сессию.

[[section-using-fixture]]
== Использование фикстуры в тесте

Чтобы использовать фикстуру, тест должен просто принять аргумент с таким же именем. `pytest` автоматически найдет и выполнит фикстуру.

```python
# test_login.py

from appium.webdriver.common.appiumby import AppiumBy

def test_username_field_is_displayed(driver): # pytest внедрит сюда результат фикстуры driver()
    username_field = driver.find_element(by=AppiumBy.ID, value="...")
    assert username_field.is_displayed()
```

Тест стал чистым. Вся логика по созданию и закрытию драйвера вынесена в фикстуру и может быть переиспользована в сотнях других тестов.
