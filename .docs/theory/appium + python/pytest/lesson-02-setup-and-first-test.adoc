[[section-setup]]
== Установка

`pytest` устанавливается как обычный Python-пакет с помощью `pip`.

```bash
pip install pytest
```

[[section-first-test]]
== Первый тест

`pytest` автоматически находит и запускает тесты, следуя простым правилам:

*   Имена файлов должны начинаться с `test_` или заканчиваться `_test.py`.
*   Имена тестовых функций должны начинаться с `test_`.

Создадим наш первый тестовый файл `test_example.py`:

```python
# test_example.py

def test_addition():
    assert 1 + 1 == 2

def test_string_concatenation():
    assert "hello" + " " + "world" == "hello world"
```

[[section-running-tests]]
== Запуск тестов

Откройте терминал в директории с вашим файлом и просто выполните команду:

```bash
pytest
```

`pytest` просканирует текущую директорию и все поддиректории, найдет файл `test_example.py` и выполнит обе функции `test_*`. Вы увидите зеленый вывод, сообщающий, что 2 теста прошли успешно.

Если изменить один из тестов, чтобы он падал (`assert 1 + 1 == 3`), `pytest` покажет подробный отчет об ошибке, сравнивая ожидаемое и фактическое значения.
