[[section-simple-assert]]
== Простой `assert`

`pytest` позволяет использовать стандартный оператор `assert` из Python для выполнения проверок. Вам больше не нужно помнить десятки методов, как в `unittest` (`assertEqual`, `assertTrue`, `assertIn` и т.д.).

```python
def test_assertions():
    a = 1
    b = 2
    my_list = [1, 2, 3]

    assert a + b == 3
    assert "hello" in "hello world"
    assert len(my_list) == 3
    assert my_list[0] == 1
```

[[section-introspection]]
== Магия интроспекции

Главное преимущество `pytest` — это **интроспекция ассертов**. Когда `assert` падает, `pytest` "заглядывает" внутрь выражения и предоставляет максимально подробный отчет о том, что пошло не так.

*Пример падения теста:*
```python
def test_failing_assertion():
    a = [1, 2, 3]
    b = [1, 2, 4]
    assert a == b
```

*Вывод `pytest`:*
```
E   assert [1, 2, 3] == [1, 2, 4]
E     At index 2 diff: 3 != 4
```

`pytest` не просто говорит, что списки не равны, он точно указывает, *в каком месте* они отличаются. Это значительно ускоряет отладку тестов.

[[section-exceptions]]
== Проверка исключений

Для проверки того, что код выбрасывает ожидаемое исключение, используется `pytest.raises`.

```python
import pytest

def test_zero_division():
    with pytest.raises(ZeroDivisionError):
        1 / 0
```

Если код внутри блока `with` не выбросит `ZeroDivisionError`, тест упадет.
