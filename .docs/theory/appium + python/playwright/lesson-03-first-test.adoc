Плагин `pytest-playwright` предоставляет "магическую" фикстуру `page`, которая избавляет нас от всей ручной работы по созданию и настройке браузера.

[[section-page-fixture]]
== Фикстура `page`

*   **Что это:** Готовый к использованию объект страницы браузера.
*   **Что делает "под капотом":** Перед каждым тестом плагин `pytest-playwright` запускает браузер, создает новый изолированный контекст и новую страницу, а после теста все это корректно закрывает.

[[section-first-test]]
== Пример первого теста

Давайте напишем простой тест, который заходит на сайт `playwright.dev` и проверяет его заголовок.

```python
# test_playwright_intro.py

from playwright.sync_api import Page, expect

def test_playwright_website_has_correct_title(page: Page):
    # 1. Переходим на сайт
    page.goto("https://playwright.dev/")

    # 2. Проверяем, что заголовок страницы содержит нужный текст
    expect(page).to_have_title("Fast and reliable end-to-end testing for modern web apps | Playwright")
```

*   **`def test_... (page: Page):`**: Мы просто объявляем аргумент `page` с типом `Page`. `pytest` и плагин `pytest-playwright` автоматически "внедрят" сюда готовую фикстуру.
*   **`page.goto(...)`**: Метод для навигации по URL.
*   **`expect(page).to_have_title(...)`**: Встроенный ассерт Playwright для проверки заголовка страницы.

[[section-running-test]]
== Запуск теста

```bash
# Запустить тест в браузере Chromium (по умолчанию)
pytest

# Запустить тест в Firefox
pytest --browser firefox

# Запустить тест во всех браузерах
pytest --browser all

# Запустить в "headless" режиме (без UI) - по умолчанию
# Запустить с UI, чтобы видеть, что происходит
pytest --headed
```
