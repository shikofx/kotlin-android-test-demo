Playwright предоставляет множество мощных инструментов "из коробки".

[[section-network-interception]]
== Перехват сетевых запросов

Вы можете перехватывать, изменять или мокировать сетевые запросы прямо в тесте. Это невероятно полезно для тестирования фронтенда в изоляции от бэкенда.

```python
def test_mock_api_response(page: Page):
    # Перехватываем все запросы к API и возвращаем фейковый JSON
    page.route(
        "**/api/products",
        lambda route: route.fulfill(
            status=200,
            json=[{"id": 1, "name": "Mock Product"}]
        )
    )

    page.goto("https://example.com/products")

    # Проверяем, что на странице отобразились наши мокированные данные
    expect(page.get_by_text("Mock Product")).to_be_visible()
```

[[section-tracing]]
== Трейсинг (Tracing)

Playwright может записывать трассировку выполнения теста, которую затем можно открыть в специальном UI (Trace Viewer) и проанализировать.

Для этого нужно запустить `pytest` с флагом `--tracing on`.

```bash
pytest --tracing on
```

После выполнения в директории `test-results` будет создан zip-архив с трассировкой. Открыть его можно командой:

```bash
playwright show-trace test-results/trace.zip
```

Trace Viewer показывает:
*   Скриншоты для каждого действия.
*   DOM-снимки до и после действия.
*   Сетевые запросы.
*   Логи консоли.

Это незаменимый инструмент для отладки упавших тестов, особенно в CI/CD.

[[section-screenshots-videos]]
== Скриншоты и видео

Playwright также может автоматически записывать видео выполнения тестов и делать скриншоты при падении.

```bash
# Записать видео для каждого теста
pytest --video on

# Сделать скриншот, только если тест упал
pytest --screenshot on
```
