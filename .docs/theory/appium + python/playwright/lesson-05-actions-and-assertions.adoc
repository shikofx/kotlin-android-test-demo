[[section-actions]]
== Действия (Actions)

Playwright предоставляет интуитивно понятные методы для взаимодействия с элементами. Все они имеют **авто-ожидания**.

*   `locator.click()`: Кликает на элемент. Playwright дождется, пока элемент станет видимым, стабильным и сможет принимать события.
*   `locator.fill("text")`: Очищает поле и вводит текст.
*   `locator.press("Enter")`: Имитирует нажатие клавиши.
*   `locator.check()`: Отмечает чекбокс.
*   `locator.uncheck()`: Снимает отметку с чекбокса.
*   `locator.select_option("value")`: Выбирает опцию в `<select>`.
*   `locator.hover()`: Наводит курсор на элемент.

[[section-assertions]]
== Проверки (`expect`)

Playwright поставляется с собственной библиотекой ассертов, которая также имеет **авто-ожидания**. Это означает, что `expect(locator).to_be_visible()` будет ждать (по умолчанию до 5 секунд), пока элемент не станет видимым, прежде чем тест упадет.

*   `expect(locator).to_be_visible()`: Элемент видим.
*   `expect(locator).to_be_hidden()`: Элемент не видим.
*   `expect(locator).to_be_enabled()`: Элемент активен.
*   `expect(locator).to_be_disabled()`: Элемент неактивен.
*   `expect(locator).to_be_checked()`: Чекбокс отмечен.
*   `expect(locator).to_have_text("...")`: Элемент содержит точный текст.
*   `expect(locator).to_contain_text("...")`: Элемент содержит подстроку.
*   `expect(locator).to_have_value("...")`: Поле ввода имеет указанное значение.
*   `expect(locator).to_have_count(3)`: Найдено ровно 3 элемента.
*   `expect(page).to_have_url("...")`: Страница имеет указанный URL.

[[section-example]]
== Пример теста

```python
from playwright.sync_api import Page, expect

def test_login_flow(page: Page):
    page.goto("https://example.com/login")

    page.get_by_label("Username").fill("tomsmith")
    page.get_by_label("Password").fill("SuperSecretPassword!")
    page.get_by_role("button", name="Login").click()

    # Проверяем, что на следующей странице есть сообщение об успехе
    success_message = page.locator("#flash")
    expect(success_message).to_contain_text("You logged into a secure area!")
```
