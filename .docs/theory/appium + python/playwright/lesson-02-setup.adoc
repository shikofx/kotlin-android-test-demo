== Установка Playwright и плагина для `pytest`

Для работы нам понадобятся две библиотеки: сам Playwright и его официальный плагин для `pytest`, который предоставляет удобные фикстуры и упрощает настройку.

1.  **Установите библиотеки с помощью `pip`:**

    ```bash
    pip install playwright
    pip install pytest-playwright
    ```

2.  **Установите браузеры:**
    После установки библиотеки Playwright необходимо скачать бинарные файлы браузеров, которыми он будет управлять. Это делается одной командой:

    ```bash
    playwright install
    ```
    Эта команда скачает последние версии Chromium, Firefox и WebKit.

[[section-requirements]]
== Файл `requirements.txt`

Хорошей практикой является добавление этих зависимостей в файл `requirements.txt`:

```
# requirements.txt
playwright
pytest
pytest-playwright
```

Теперь любой, кто скачает ваш проект, сможет установить все необходимое одной командой `pip install -r requirements.txt`.
