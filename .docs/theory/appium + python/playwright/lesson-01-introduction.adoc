== Что такое Playwright?

**Playwright** — это open-source фреймворк от Microsoft для автоматизации современных веб-приложений. Он позволяет управлять браузерами Chromium (Chrome, Edge), Firefox и WebKit (Safari) с помощью единого API.

Хотя Playwright и Selenium решают одну и ту же задачу, Playwright был создан с нуля с учетом недостатков своего предшественника и предлагает ряд кардинальных улучшений.

[[section-key-features]]
== Ключевые преимущества Playwright

1.  **Автоматические ожидания (Auto-waits):** Это главная "фишка". Playwright автоматически ждет, пока элемент станет доступным для взаимодействия (например, видимым и кликабельным), прежде чем выполнить действие. Это устраняет 99% проблем с "flaky" тестами, связанных с ожиданиями.

2.  **Надежные локаторы:** Playwright продвигает использование локаторов, ориентированных на пользователя (`get_by_role`, `get_by_text`), которые менее подвержены поломкам при изменении верстки, в отличие от хрупких XPath.

3.  **Мощные встроенные проверки (`expect`):** Встроенный механизм ассертов также имеет авто-ожидания. `expect(locator).to_have_text("...")` будет ждать, пока у элемента не появится нужный текст.

4.  **Перехват сетевых запросов:** Playwright позволяет легко мокировать и проверять сетевые запросы "из коробки", без необходимости в сторонних прокси-серверах.

5.  **Изоляция тестов:** Каждый тест получает свой собственный "контекст" браузера (аналог профиля инкогнито), что обеспечивает полную изоляцию кук, `localStorage` и т.д.

6.  **Отличные инструменты отладки:** Playwright Trace Viewer — это мощный инструмент, который позволяет после прогона теста "проиграть" его шаг за шагом, видя DOM-снимки, сетевые запросы и логи.
