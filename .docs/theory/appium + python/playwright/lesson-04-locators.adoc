Playwright настоятельно рекомендует использовать локаторы, которые ориентированы на пользователя, а не на детали верстки. Это делает тесты более надежными и устойчивыми к изменениям.

[[section-recommended-locators]]
== Рекомендуемые локаторы

*   **`page.get_by_role(role, name=...)`**: Самый предпочтительный локатор. Ищет элементы по их ARIA-роли. Например, `role="button"`, `role="checkbox"`. Можно уточнить по имени (тексту).
    `page.get_by_role("button", name="Sign in")`

*   **`page.get_by_text("...")`**: Ищет элемент по содержащемуся в нем тексту.
    `page.get_by_text("Welcome, user!")`

*   **`page.get_by_label("...")`**: Ищет элемент по тексту связанного с ним `<label>`.
    `page.get_by_label("Password")`

*   **`page.get_by_placeholder("...")`**: Ищет по тексту плейсхолдера.
    `page.get_by_placeholder("Enter your email")`

*   **`page.get_by_test_id("...")`**: Ищет по атрибуту `data-testid`. Это специальный атрибут, который добавляется в верстку специально для тестов и не меняется.
    `page.get_by_test_id("login-form")`

[[section-legacy-locators]]
== Классические локаторы

Playwright также поддерживает классические локаторы, но их рекомендуется использовать, только если современные не подходят.

*   **`page.locator("css=...")`** или **`page.locator(".my-class")`**: Поиск по CSS-селектору.
*   **`page.locator("xpath=...")`**: Поиск по XPath.

```python
# Пример

def test_login_form(page: Page):
    # Хорошо: ищем кнопку по роли и имени
    login_button = page.get_by_role("button", name="Login")

    # Допустимо: ищем по test-id
    username_input = page.get_by_test_id("username-input")

    # Плохо: привязка к хрупкому CSS-классу
    password_input = page.locator(".form-control.password-field")
```
