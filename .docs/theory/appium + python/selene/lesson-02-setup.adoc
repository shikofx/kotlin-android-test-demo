[[section-dependencies]]
== 1. Добавление зависимостей

Установите библиотеку `selene` с помощью `pip`.

```bash
pip install selene
```

Добавьте ее в ваш `requirements.txt`:
```
# requirements.txt
Appium-Python-Client
pytest
selene
```

[[section-driver-configuration]]
== 2. Конфигурация драйвера

`selene` работает с глобальным объектом `browser`, который является оберткой над драйвером. Нам нужно сконфигурировать этот объект, чтобы он использовал наш Appium-драйвер.

Модифицируем нашу фикстуру в `conftest.py`:

```python
# conftest.py

import pytest
from appium import webdriver
from appium.options.android import UiAutomator2Options
from selene import browser

@pytest.fixture(scope="function")
def mobile_management():
    options = UiAutomator2Options().load_capabilities(...) # Ваши capabilities

    with webdriver.Remote("http://127.0.0.1:4723", options=options) as driver:
        browser.config.driver = driver
        yield
```

=== Что здесь происходит?

1.  **`from selene import browser`**: Мы импортируем глобальный объект `browser`.
2.  **`browser.config.driver = driver`**: Это ключевая строка. Мы присваиваем созданный Appium-драйвер конфигурации `selene`. Теперь все команды `selene` будут выполняться через этот драйвер.
3.  **`with webdriver.Remote(...) as driver:`**: Мы используем `with`, чтобы драйвер автоматически закрывался после завершения теста.
4.  **`yield`**: Фикстура просто выполняет настройку и передает управление тесту. Тесту больше не нужно принимать `driver` в качестве аргумента, так как он может использовать глобальный `browser` из `selene`.
