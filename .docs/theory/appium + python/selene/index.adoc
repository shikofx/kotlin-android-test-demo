Добро пожаловать в курс по **`selene`** — Python-аналогу знаменитого фреймворка Selenide. `selene` — это умная обертка над Selenium WebDriver (и, соответственно, над Appium), которая избавляет от большинства шаблонного кода, связанного с ожиданиями и проверками, делая ваши тесты короче, стабильнее и на порядок читабельнее.
