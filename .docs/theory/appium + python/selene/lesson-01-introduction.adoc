[[section-what-is-selene]]
== Что такое `selene`?

**`selene`** — это библиотека для Python, которая является идейным наследником и аналогом популярного Java-фреймворка Selenide. Она предоставляет высокоуровневый DSL (предметно-ориентированный язык) для написания UI-тестов, который скрывает сложность Selenium WebDriver / Appium.

Основная цель `selene` — сделать тесты максимально читаемыми и избавить тестировщика от рутины.

[[section-problems-selene-solves]]
== Какие проблемы Appium решает `selene`?

1.  **Явные ожидания (Explicit Waits):** В чистом Appium вам постоянно нужно писать код для ожидания появления элементов (`WebDriverWait`). `selene` делает это **автоматически**. Когда вы обращаетесь к элементу, `selene` сам ждет его появления в течение заданного таймаута.

2.  **Громоздкий поиск элементов:** Вместо `driver.find_element(...)` вы пишете лаконичное `s(...)`.

3.  **Нечитаемые проверки:** Вместо `assert element.is_displayed()` вы пишете `element.should(be.visible)`.

=== Сравнение "До" и "После"

*Чистый Appium:*
```python
wait = WebDriverWait(driver, 10)
element = wait.until(EC.visibility_of_element_located((AppiumBy.ID, "...")))
element.click()
assert element.text == "Hello"
```

*С `selene`:*
```python
from selene import have

element = s((AppiumBy.ID, "..."))
element.click()
element.should(have.text("Hello"))
```

Разница колоссальна. `selene` позволяет сфокусироваться на бизнес-логике теста, а не на технических деталях.
