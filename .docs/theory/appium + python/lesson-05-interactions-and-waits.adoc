[[section-actions]]
== Базовые взаимодействия

API для взаимодействия с элементами в Python-клиенте очень простое и интуитивное.

*   `element.click()`: Нажатие на элемент.
*   `element.send_keys("text")`: Ввод текста.
*   `element.clear()`: Очистка текстового поля.
*   `element.text`: Получение текста элемента (это свойство, а не метод).
*   `element.is_displayed()`: Проверка, видим ли элемент.
*   `element.is_enabled()`: Проверка, активен ли элемент.

[[section-waits-problem]]
== Проблема: нестабильные тесты

Appium, в отличие от Espresso, не имеет встроенной синхронизации с UI-потоком. Если вы попытаетесь найти элемент, который еще не появился на экране (например, из-за анимации или сетевой задержки), ваш тест упадет с ошибкой `NoSuchElementException`.

**Плохой подход:** `time.sleep(5)` — это делает тесты медленными и ненадежными.

**Правильный подход:** **Явные ожидания (Explicit Waits)**. Мы говорим драйверу: "Подожди до X секунд, пока не выполнится определенное условие (например, пока элемент не станет видимым), и только потом продолжай".

[[section-webdriverwait]]
== Использование `WebDriverWait`

Для явных ожиданий используется связка `WebDriverWait` и `expected_conditions`.

```python
# test_login.py

from appium.webdriver.common.appiumby import AppiumBy
from selenium.webdriver.support.ui import WebDriverWait
from selenium.webdriver.support import expected_conditions as EC

def test_successful_login(driver):
    # Создаем объект ожидания. Будем ждать до 10 секунд.
    wait = WebDriverWait(driver, 10)

    # Ждем, пока поле username не станет видимым, и только потом вводим текст
    username_field = wait.until(
        EC.visibility_of_element_located((AppiumBy.ID, "com.example.app:id/username_input"))
    )
    username_field.send_keys("standard_user")

    # Для остальных элементов можно сделать так же
    password_field = driver.find_element(by=AppiumBy.ID, value="com.example.app:id/password_input")
    password_field.send_keys("secret_sauce")

    login_button = driver.find_element(by=AppiumBy.ID, value="com.example.app:id/login_button")
    login_button.click()

    # Ждем появления заголовка на следующем экране
    products_title = wait.until(
        EC.visibility_of_element_located((AppiumBy.XPATH, "//*[@text='Products']"))
    )

    # Проверяем, что заголовок видим
    assert products_title.is_displayed()
```

*   `WebDriverWait(driver, 10)`: Создает экземпляр "ожидателя".
*   `wait.until(...)`: Блокирует выполнение, пока условие внутри не станет истинным, или пока не истечет таймаут.
*   `EC.visibility_of_element_located(...)`: Одно из многих готовых условий. Оно ждет, пока элемент не только появится в иерархии, но и станет видимым на экране.

Использование явных ожиданий — это ключ к написанию стабильных и надежных Appium-тестов.
