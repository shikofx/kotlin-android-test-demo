= Тестирование Network.java с помощью Ktor Client Mock

В этой серии уроков мы изучим, как использовать `ktor-client-mock` для тестирования нашего класса `Network.java`. Этот инструмент позволяет создавать быстрые и надежные тесты для сетевого слоя, написанного с использованием Ktor.

Мы полностью покроем цели, изначально поставленные в `TESTING_STRATEGY.md` для `MockWebServer`, но с помощью более легковесного и идиоматичного для Ktor подхода.

== План тестирования (цели)

* Проверить корректность формирования GET и POST запросов.
* Проверить добавление заголовков `User-Agent` и `X-Trace-ID`.
* Проверить обработку успешных (200) и ошибочных (4xx, 5xx) ответов.
