MockK предоставляет мощные инструменты для мокирования специфичных для Kotlin конструкций.

[[section-coroutines]]
== Тестирование корутин (`suspend` функций)

Для работы с `suspend` функциями используются аналоги `every` и `verify` с префиксом `co`:

*   `coEvery { ... } returns ...`
*   `coVerify { ... }`

```kotlin
@Test
fun `test suspend function`() = runTest { // Используем runTest из kotlinx-coroutines-test
    // Arrange
    val remoteDataSource: RemoteDataSource = mockk()
    coEvery { remoteDataSource.fetchProducts() } returns listOf(product1)

    // Act
    val result = remoteDataSource.fetchProducts()

    // Assert
    coVerify { remoteDataSource.fetchProducts() }
    result shouldHaveSize 1
}
```

[[section-objects]]
== Мокирование `object` (синглтонов)

MockK позволяет мокировать синглтоны с помощью `mockkObject`.

```kotlin
object MySingleton {
    fun doSomething(): String = "Real value"
}

@Test
fun `test object mock`() {
    mockkObject(MySingleton) // Начинаем мокировать объект
    every { MySingleton.doSomething() } returns "Mocked value"

    MySingleton.doSomething() shouldBe "Mocked value"

    unmockkObject(MySingleton) // Возвращаем объекту реальное поведение
}
```

[[section-statics]]
== Мокирование статических методов

Аналогично объектам, можно мокировать статические методы Java-классов с помощью `mockkStatic`.

```kotlin
mockkStatic(Log::class)
every { Log.d(any(), any()) } returns 0 // Мокируем статический метод Log.d
```

Эти возможности делают MockK незаменимым инструментом для тестирования реальных Android-приложений, где часто встречаются корутины, синглтоны и вызовы статических методов Android SDK.
