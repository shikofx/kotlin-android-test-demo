[[section-json-files]]
== Хранение ответов в JSON-файлах

Хранить JSON-строки прямо в коде теста — плохая практика. Это делает тесты громоздкими и трудными для поддержки.

**Лучше:** Хранить JSON-ответы в отдельных файлах в директории `src/androidTest/resources`.

*   Создайте файл `src/androidTest/resources/responses/success_login.json`.
*   Напишите утилиту для чтения файла в строку.

```kotlin
// Вспомогательная функция
fun readStringFromFile(fileName: String): String {
    val inputStream = javaClass.classLoader?.getResourceAsStream(fileName)
    return inputStream?.bufferedReader()?.use { it.readText() } ?: ""
}

// В тесте
@Test
fun `test with json file`() {
    val responseBody = readStringFromFile("responses/success_login.json")
    server.enqueue(MockResponse().setBody(responseBody))
    // ...
}
```

[[section-kaspresso-integration]]
== Интеграция с Kaspresso

`MockWebServer` отлично сочетается с Kaspresso для написания полноценных E2E-тестов, изолированных от реального бэкенда.

```kotlin
class LoginFlowTest : TestCase() {

    private val server = MockWebServer()

    @Test
    fun successfulLoginFlow() = before {
        server.start(8080) // Запускаем на известном порту
        // В DI-фреймворке (Hilt, Koin) мы подменяем базовый URL,
        // который использует Network.java, на "http://localhost:8080"
    }.after {
        server.shutdown()
    }.run {
        step("Подготовка ответа от сервера") {
            val productsJson = readStringFromFile("responses/products_success.json")
            val response = MockResponse().setResponseCode(200).setBody(productsJson)
            server.enqueue(response)
        }

        step("Выполнение UI-сценария") {
            LoginScreen {
                // ... действия на экране логина
                loginButton.click()
            }
        }

        step("Проверка результата на UI") {
            ProductCatalogScreen {
                // Проверяем, что список товаров отобразился
                recycler.hasSize(1)
                firstChild<ProductItem> {
                    title.hasText("Test Product")
                }
            }
        }
    }
}
```

Используя `MockWebServer` в связке с Kaspresso, вы можете создавать очень мощные, быстрые и надежные UI-тесты для самых сложных сценариев.
