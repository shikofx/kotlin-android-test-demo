Добро пожаловать в курс по **MockWebServer** — мощной библиотеке от Square для тестирования сетевого слоя. Этот курс научит вас, как писать быстрые и надежные интеграционные тесты. В качестве примера мы будем использовать эту библиотеку для тестирования нашего класса `Network.java`, который работает с Ktor `HttpClient`.
