== Что такое Espresso?

**Espresso** (`androidx.test.espresso:espresso-core`) — это основной фреймворк для написания UI-тестов в Android. Он является частью набора AndroidX Test и предоставляет простой и мощный API для взаимодействия с UI вашего приложения.

Ключевая особенность Espresso — автоматическая синхронизация. Он ждет, пока UI-поток будет свободен, прежде чем выполнить следующее действие или проверку. Это избавляет от необходимости писать `Thread.sleep()` и делает тесты более стабильными.

[[section-espresso-core-api]]
== Основное API Espresso

Тест на Espresso обычно состоит из трех частей, которые вместе образуют одну инструкцию:

```kotlin
onView(ViewMatcher).perform(ViewAction).check(ViewAssertion)
```

1.  **`onView(ViewMatcher)`**: Находит элемент на экране.
    *   **`ViewMatcher`** — это условие для поиска.
    *   Примеры: `withId(R.id.my_button)`, `withText("Login")`, `withHint("Password")`.

2.  **`.perform(ViewAction)`**: Выполняет действие над найденным элементом.
    *   **`ViewAction`** — это само действие.
    *   Примеры: `click()`, `typeText("hello")`, `scrollTo()`, `clearText()`.

3.  **`.check(ViewAssertion)`**: Проверяет состояние элемента.
    *   **`ViewAssertion`** — это проверка (ассерт).
    *   Примеры: `matches(isDisplayed())`, `matches(withText("Success"))`, `doesNotExist()`.

=== Пример полного теста

```kotlin
@Test
fun login_withCorrectCredentials_showsSuccess() {
    // Найти поле username, очистить его и ввести "standard_user"
    onView(withId(R.id.username_input))
        .perform(clearText(), typeText("standard_user"))

    // Найти кнопку login и нажать на нее
    onView(withId(R.id.login_button)).perform(click())

    // Проверить, что на следующем экране отображается текст "Products"
    onView(withText("Products")).check(matches(isDisplayed()))
}
```

Espresso — это мощный инструмент, который лежит в основе многих других фреймворков для UI-тестирования, таких как Kakao и Kaspresso. Понимание его базовых принципов является обязательным для любого Android-тестировщика.
