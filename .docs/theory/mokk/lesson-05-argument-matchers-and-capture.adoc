Часто нам не важно, с каким именно значением был вызван метод, или мы хотим проверить только часть аргументов. Для этого используются **матчеры аргументов**.

[[section-argument-matchers]]
== Матчеры аргументов

*   `any()`: Любое значение указанного типа.
*   `eq(value)`: Значение, равное `value`. Используется, когда другие аргументы являются матчерами.
*   `more(value)`, `less(value)`: Для числовых сравнений.
*   `ofType<Type>()`: Любое значение указанного типа.

```kotlin
@Test
fun `test with argument matchers`() {
    val repository: DatabaseRepository = mockk(relaxed = true)

    // Стабинг: когда getProduct вызывается с любым Int, вернуть product1
    every { repository.getProduct(any()) } returns MutableLiveData(product1)

    // Верификация: проверить, что метод insertProduct был вызван с любым объектом Product
    verify { repository.insertProduct(any()) }

    // Верификация: проверить, что метод getProduct был вызван со значением, меньшим 10
    verify { repository.getProduct(less(10)) }
}
```

[[section-capturing-arguments]]
== Захват аргументов (`capture`)

Иногда нужно не просто проверить тип аргумента, а выполнить над ним сложные проверки. Для этого используется механизм захвата.

```kotlin
@Test
fun `test argument capturing`() {
    val repository: DatabaseRepository = mockk(relaxed = true)
    val capturedProduct = slot<Product>() // Создаем "слот" для захвата

    // Верифицируем вызов и одновременно захватываем аргумент
    verify { repository.insertProduct(capture(capturedProduct)) }

    // Теперь мы можем выполнять проверки над захваченным значением
    val product = capturedProduct.captured
    product.name shouldStartWith "Test"
    product.price shouldBeGreaterThan 0.0
}
```

Захват аргументов — очень мощный инструмент для детальной проверки данных, которые передаются в ваши моки.
