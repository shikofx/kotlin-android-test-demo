**Верификация** — это процесс проверки того, что методы мока были вызваны так, как мы ожидали. В MockK это делается с помощью блока `verify { ... }`.

[[section-basic-verification]]
== Базовая верификация

По умолчанию `verify` проверяет, что метод был вызван **ровно один раз**.

```kotlin
@Test
fun `test basic verification`() {
    // Arrange
    val repository: DatabaseRepository = mockk(relaxed = true)

    // Act
    repository.getProducts()

    // Assert
    verify { repository.getProducts() }
}
```

[[section-verifying-call-count]]
== Проверка количества вызовов

Вы можете точно указать, сколько раз должен был быть вызван метод.

*   `verify(exactly = 2) { repository.doSomething() }` — ровно 2 раза.
*   `verify(atLeast = 1) { repository.doSomething() }` — как минимум 1 раз.
*   `verify(atMost = 5) { repository.doSomething() }` — не более 5 раз.
*   `verify(exactly = 0) { repository.doSomething() }` — не был вызван ни разу.

[[section-verifying-order]]
== Проверка порядка вызовов

Иногда важен не только сам факт вызова, но и порядок.

=== `verifyOrder`

Проверяет, что вызовы были сделаны в указанном порядке, но между ними могли быть и другие вызовы.
```kotlin
verifyOrder {
    repository.stepOne()
    repository.stepThree()
}
```

=== `verifySequence`

Проверяет, что вызовы были сделаны *строго* в указанном порядке, и никаких других вызовов между ними не было.
```kotlin
verifySequence {
    repository.stepOne()
    repository.stepTwo()
}
```
