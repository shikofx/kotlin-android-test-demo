Добро пожаловать в курс по тестированию **Android Architecture Components (AAC)**. Современные Android-приложения строятся на основе компонентов, таких как `ViewModel`, `LiveData` и `Room`, а также используют корутины и `Flow` для асинхронных операций. Этот курс научит вас, как писать надежные и изолированные тесты для каждого из этих элементов.
