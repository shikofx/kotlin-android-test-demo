Добро пожаловать в курс по **JUnit 4 Rules**. Несмотря на то, что JUnit 5 является современным стандартом, экосистема Android-тестирования исторически тесно связана с JUnit 4. Ключевые библиотеки, такие как `AndroidX Test`, предоставляют основные инструменты в виде `@Rule` (например, `ActivityScenarioRule`). Понимание этого механизма абсолютно необходимо для любого Android-тестировщика.
