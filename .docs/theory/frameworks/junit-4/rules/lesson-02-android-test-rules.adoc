Библиотеки `AndroidX Test` предоставляют несколько чрезвычайно полезных правил, которые являются стандартом для инструментальных тестов.

[[section-activityscenariorule]]
== `ActivityScenarioRule`

Это самое важное и часто используемое правило в UI-тестировании.

*   **Что делает:** Автоматически запускает указанную `Activity` перед каждым тестом и корректно завершает ее после теста.
*   **Зачем нужно:** Обеспечивает, что каждый UI-тест начинается с чистого, свежего экземпляра `Activity`, гарантируя изоляцию тестов.

=== Пример использования

```kotlin
import androidx.test.ext.junit.rules.ActivityScenarioRule
import com.example.app.ui.login.LoginActivity
import org.junit.Rule

class LoginActivityTest {

    @get:Rule
    var activityRule = ActivityScenarioRule(LoginActivity::class.java)

    // ... тесты для LoginActivity
}
```

[[section-grantpermissionrule]]
== `GrantPermissionRule`

Это правило позволяет программно предоставить приложению необходимые разрешения во время выполнения теста. Это избавляет от необходимости вручную обрабатывать системные диалоги запроса разрешений.

=== Пример использования

```kotlin
import androidx.test.rule.GrantPermissionRule

@get:Rule
var permissionRule = GrantPermissionRule.grant(android.Manifest.permission.CAMERA)
```

Вы можете перечислить несколько разрешений через запятую. JUnit гарантирует, что эти разрешения будут предоставлены вашему приложению на время выполнения теста.
