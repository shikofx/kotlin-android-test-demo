[[section-what-is-rule]]
== Что такое `@Rule`?

**`@Rule`** — это механизм в JUnit 4, который позволяет добавлять или переопределять поведение тестовых методов. Правило — это объект, который "оборачивает" выполнение теста, позволяя выполнять код до и после него.

Это более мощная и гибкая альтернатива методам, аннотированным `@Before` и `@After`, поскольку правила можно легко переиспользовать между разными тестовыми классами и комбинировать.

[[section-how-it-works]]
== Как это работает?

Вы объявляете публичное поле в вашем тестовом классе, аннотируете его `@Rule` (или `@get:Rule` в Kotlin), и JUnit автоматически применяет его к каждому тестовому методу в классе.

```kotlin
import org.junit.Rule

class MyTest {
    @get:Rule
    val myRule = MyCustomRule()

    // ... тесты
}
```

[[section-rule-vs-classrule]]
== `@Rule` vs `@ClassRule`

*   **`@Rule`**: Применяется к каждому тестовому методу. Объект правила создается заново для каждого теста.
*   **`@ClassRule`**: Применяется один раз ко всему тестовому классу. Используется для тяжелых операций, которые нужно выполнить один раз (например, запуск внешнего сервера).

В Android-тестировании вы почти всегда будете сталкиваться с `@Rule`.
