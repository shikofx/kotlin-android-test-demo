Параллельное выполнение в JUnit 5 включается и настраивается декларативно через конфигурационный файл.

[[section-properties-file]]
== Файл `junit-platform.properties`

Чтобы включить параллелизацию, создайте файл `junit-platform.properties` в директории `src/test/resources`.

=== Пример конфигурации

```properties
# src/test/resources/junit-platform.properties

# Включаем параллельное выполнение
junit.jupiter.execution.parallel.enabled = true

# Указываем, что и классы, и методы внутри них могут выполняться параллельно
junit.jupiter.execution.parallel.mode.default = concurrent
junit.jupiter.execution.parallel.mode.classes.default = concurrent

# Настраиваем стратегию определения количества потоков
junit.jupiter.execution.parallel.config.strategy = dynamic
junit.jupiter.execution.parallel.config.dynamic.factor = 1.0
```

[[section-config-options]]
== Основные параметры конфигурации

*   **`junit.jupiter.execution.parallel.enabled`**:
    *   `true`: Включает параллельное выполнение.
    *   `false` (по умолчанию): Все тесты выполняются последовательно.

*   **`junit.jupiter.execution.parallel.mode.default`**:
    *   `same_thread` (по умолчанию): Тестовые методы внутри класса выполняются в том же потоке, что и сам класс.
    *   `concurrent`: Тестовые методы внутри класса могут выполняться параллельно друг с другом.

*   **`junit.jupiter.execution.parallel.config.strategy`**:
    *   `dynamic` (по умолчанию): Количество потоков вычисляется на основе количества ядер процессора, умноженного на `dynamic.factor`.
    *   `fixed`: Используется фиксированное количество потоков, заданное в `config.fixed.parallelism`.
    *   `custom`: Позволяет задать свою реализацию `ParallelExecutionConfigurationStrategy`.

Включив эти параметры, вы уже получите базовую параллелизацию. В следующих уроках мы научимся управлять ею более тонко.
