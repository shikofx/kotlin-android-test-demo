Колбэки жизненного цикла — это самый простой и распространенный тип расширений. Они позволяют выполнять код на различных этапах выполнения тестов.

[[section-callback-interfaces]]
== Интерфейсы колбэков

*   `BeforeAllCallback`: Выполняется один раз *перед* всеми тестами в классе. Аналог `@BeforeAll`.
*   `AfterAllCallback`: Выполняется один раз *после* всех тестов в классе. Аналог `@AfterAll`.
*   `BeforeEachCallback`: Выполняется *перед каждым* тестовым методом. Аналог `@BeforeEach`.
*   `AfterEachCallback`: Выполняется *после каждого* тестового метода. Аналог `@AfterEach`.
*   `BeforeTestExecutionCallback`: Выполняется непосредственно *перед* выполнением тела тестового метода (после `@BeforeEach`).
*   `AfterTestExecutionCallback`: Выполняется непосредственно *после* выполнения тела тестового метода (до `@AfterEach`).

[[section-example]]
== Пример: Расширение для логирования

Давайте создадим простое расширение, которое будет логировать начало и конец каждого теста.

```kotlin
import org.junit.jupiter.api.extension.AfterEachCallback
import org.junit.jupiter.api.extension.BeforeEachCallback
import org.junit.jupiter.api.extension.ExtensionContext
import java.util.logging.Logger

class LoggingExtension : BeforeEachCallback, AfterEachCallback {

    companion object {
        private val logger = Logger.getLogger(LoggingExtension::class.java.name)
    }

    override fun beforeEach(context: ExtensionContext) {
        logger.info { "Starting test: ${context.displayName}" }
    }

    override fun afterEach(context: ExtensionContext) {
        logger.info { "Finished test: ${context.displayName}" }
    }
}
```

=== Использование расширения

```kotlin
@ExtendWith(LoggingExtension::class)
class MySampleTest {

    @Test
    fun `simple passing test`() {
        // ...
    }
}
```

Перед запуском `simple passing test` будет вызван `beforeEach`, а после его завершения — `afterEach`. Объект `ExtensionContext` предоставляет полезную информацию о текущем тесте, например, его отображаемое имя (`displayName`).
