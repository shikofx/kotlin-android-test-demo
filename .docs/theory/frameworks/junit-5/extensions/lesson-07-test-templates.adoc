== Что такое Шаблоны Тестов?

Шаблонный тест, помеченный аннотацией `@TestTemplate`, сам по себе не является исполняемым тестом. Это шаблон, который может быть выполнен несколько раз в зависимости от контекста, предоставленного расширениями.

Для создания шаблонных тестов используется интерфейс `TestTemplateInvocationContextProvider`. Он должен вернуть поток (Stream) объектов `TestTemplateInvocationContext`. Каждый такой объект представляет один вызов шаблонного теста.

Встроенные аннотации `@RepeatedTest` и `@ParameterizedTest` являются реализациями этой концепции.

[[section-example]]
== Пример: Повторение теста с разным контекстом

Давайте создадим расширение, которое запускает тест дважды: один раз для "USER" и один раз для "ADMIN".

```kotlin
import org.junit.jupiter.api.extension.*
import java.util.stream.Stream

class UserRoleExtension : TestTemplateInvocationContextProvider {

    // Проверяем, можем ли мы предоставить контекст для этого шаблонного теста
    override fun supportsTestTemplate(context: ExtensionContext): Boolean {
        return true
    }

    // Предоставляем контексты для вызовов
    override fun provideTestTemplateInvocationContexts(context: ExtensionContext): Stream<TestTemplateInvocationContext> {
        return Stream.of(
            invocationContext("USER"),
            invocationContext("ADMIN")
        )
    }

    private fun invocationContext(role: String): TestTemplateInvocationContext {
        return object : TestTemplateInvocationContext {
            // Задаем отображаемое имя для каждого вызова
            override fun getDisplayName(invocationIndex: Int): String = "with role: $role"
        }
    }
}

@ExtendWith(UserRoleExtension::class)
class MyTemplateTest {

    @TestTemplate // Это шаблон, а не обычный тест
    fun `test something for different roles`() {
        // ...
    }
}
```

В результатах тестового прогона вы увидите два выполненных теста: `test something for different roles with role: USER` и `test something for different roles with role: ADMIN`.
