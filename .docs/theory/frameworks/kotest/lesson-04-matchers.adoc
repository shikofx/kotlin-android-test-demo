Kotest предоставляет богатую библиотеку матчеров, которые делают код проверок (ассертов) более читаемым и похожим на естественный язык.

[[section-basic-matchers]]
== Основные матчеры

```kotlin
import io.kotest.matchers.shouldBe
import io.kotest.matchers.shouldNotBe
import io.kotest.matchers.string.shouldStartWith

val name = "Kotest"

name shouldBe "Kotest"
name shouldNotBe "JUnit"
name.shouldStartWith("Ko")
```

[[section-collection-matchers]]
== Матчеры для коллекций

```kotlin
import io.kotest.matchers.collections.shouldHaveSize
import io.kotest.matchers.collections.shouldContain
import io.kotest.matchers.collections.shouldBeEmpty

val numbers = listOf(1, 2, 3)

numbers.shouldHaveSize(3)
numbers.shouldContain(2)

val emptyList = emptyList<Int>()
emptyList.shouldBeEmpty()
```

[[section-exception-matchers]]
== Проверка исключений

```kotlin
import io.kotest.assertions.throwables.shouldThrow

shouldThrow<IllegalArgumentException> {
    // Код, который должен выбросить исключение
    require(false) { "This should fail" }
}
```

Использование матчеров Kotest делает тесты не только более читаемыми, но и более информативными при падении, так как сообщения об ошибках часто бывают более понятными, чем у стандартных ассертов.
