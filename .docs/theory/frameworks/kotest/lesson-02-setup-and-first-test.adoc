== Настройка

Для использования Kotest в вашем проекте необходимо добавить несколько зависимостей в `build.gradle.kts`.

```kotlin
// build.gradle.kts (app)

dependencies {
    // Runner для запуска тестов Kotest через платформу JUnit 5
    testImplementation("io.kotest:kotest-runner-junit5:5.8.0") // Уточните последнюю версию

    // Библиотека с матчерами (shouldBe и т.д.)
    testImplementation("io.kotest:kotest-assertions-core:5.8.0")

    // Для property-based testing (опционально, но рекомендуется)
    testImplementation("io.kotest:kotest-property:5.8.0")
}
```

[[section-first-test]]
== Первый тест с `StringSpec`

`StringSpec` — это самый простой стиль в Kotest. Он очень похож на JUnit: вы просто создаете функции, имена которых являются описанием теста.

```kotlin
import io.kotest.core.spec.style.StringSpec
import io.kotest.matchers.shouldBe

class MyFirstKotestTest : StringSpec({

    "length of 'hello' should be 5" {
        "hello".length shouldBe 5
    }

    "string should start with 'world'" {
        val myString = "world of testing"
        myString.startsWith("world") shouldBe true
    }
})
```

=== Что здесь происходит?

*   `class MyFirstKotestTest : StringSpec({ ... })`: Тестовый класс наследуется от одного из стилей Kotest (в данном случае `StringSpec`) и передает лямбда-выражение в конструктор.
*   `"length of 'hello' should be 5" { ... }`: Строковый литерал становится именем теста. Это очень удобно для описания поведения.
*   `shouldBe`: Это матчер из Kotest. `a shouldBe b` является аналогом `assertEquals(b, a)`.
