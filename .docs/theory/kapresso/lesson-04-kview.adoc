[[section-what-is-kview]]
== Что такое KView?

**KView** — это "умная" обертка над `View` из Android. Это не новая концепция, придуманная Kaspresso, а основанная на библиотеке **Kakao**. Kaspresso берет `KView` из Kakao и значительно расширяет его, добавляя свои механизмы стабильности.

Каждый элемент, который вы объявляете в `KScreen` (например, `KButton`, `KEditText`, `KTextView`), является наследником `KView`.

[[section-kview-power]]
== В чем сила KView в Kaspresso?

Когда вы вызываете метод у `KView`, например `loginButton.click()`, Kaspresso не просто выполняет стандартное действие Espresso. Он запускает целый конвейер, который обеспечивает стабильность теста:

1.  **Ожидание (Wait):** Kaspresso сначала ждет, пока элемент появится на экране и станет доступным для взаимодействия.
2.  **Повторные попытки (Retry):** Если действие не удалось с первой попытки (например, элемент был временно перекрыт другим View), Kaspresso автоматически повторит его несколько раз в течение заданного таймаута.
3.  **Логирование:** Каждая попытка и каждое действие подробно логируются.
4.  **Обработка ошибок:** Если после всех попыток действие так и не удалось, Kaspresso выбросит информативное исключение со скриншотом и детальным описанием проблемы.

Это избавляет вас от необходимости писать `Thread.sleep()` или сложные `IdlingResource` для обработки простых анимаций или небольших задержек в UI.

[[section-kview-api]]
== API для взаимодействия

`KView` и его наследники предоставляют интуитивно понятный DSL для действий и проверок.

*   **Действия (Actions):**
    *   `click()`
    *   `doubleClick()`
    *   `longClick()`
    *   `typeText("some text")` (для `KEditText`)
    *   `scrollTo()`

*   **Проверки (Assertions):**
    *   `isDisplayed()` / `isNotDisplayed()`
    *   `isVisible()` / `isInvisible()`
    *   `isEnabled()` / `isDisabled()`
    *   `hasText("some text")` (для `KTextView`)
    *   `hasHint("some hint")` (для `KEditText`)

Сравните:
*   **Espresso:** `onView(withId(R.id.login_button)).check(matches(isDisplayed()))`
*   **Kaspresso:** `loginButton.isDisplayed()`

Код становится не только короче, но и гораздо более читаемым.
