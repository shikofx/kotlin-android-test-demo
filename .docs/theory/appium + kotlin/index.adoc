Добро пожаловать в курс по **Appium** — ведущему open-source фреймворку для автоматизации мобильных приложений. В отличие от Espresso/Kaspresso, Appium работает по принципу "черного ящика" (black-box), что позволяет писать тесты на любом языке и тестировать взаимодействие с системой. Этот курс научит вас основам автоматизации Android-приложений с помощью Appium и Kotlin.
