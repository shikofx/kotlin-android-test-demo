После запуска драйвера следующим шагом является поиск UI-элементов на экране. Appium предоставляет несколько стратегий поиска (локаторов).

[[section-locators]]
== Основные стратегии локаторов

=== 1. ID

*   **Что это:** `resource-id` элемента, который вы видите в Appium Inspector. Это то же самое, что и `android:id` в XML-разметке.
*   **Как использовать:** `AppiumBy.id("com.example.app:id/username_input")`
*   **Когда использовать:** **Это самый надежный и предпочтительный способ.** ID, как правило, уникальны и не меняются при изменении текста или положения элемента.

=== 2. Accessibility ID

*   **Что это:** `content-description` элемента (`android:contentDescription`).
*   **Как использовать:** `AppiumBy.accessibilityId("Login Button")`
*   **Когда использовать:** Очень хороший и надежный способ. Идеален для элементов, у которых нет ID (например, иконки без текста). Также важен для доступности (accessibility) приложения.

=== 3. XPath

*   **Что это:** Путь к элементу в XML-иерархии экрана.
*   **Как использовать:** `AppiumBy.xpath("//android.widget.Button[@text='Войти']")`
*   **Когда использовать:** **Только в крайнем случае!** XPath — самый медленный и хрупкий локатор. Любое изменение в структуре экрана может сломать его. Используйте его, только если у элемента нет ни ID, ни Accessibility ID.

=== Другие локаторы

*   `AppiumBy.className("android.widget.Button")`: Поиск по имени класса.
*   `AppiumBy.name("text")` или `AppiumBy.linkText("text")`: Поиск по тексту элемента. Не рекомендуется, так как тесты сломаются при смене локализации.

[[section-finding-elements]]
== Поиск элемента в коде

Для поиска элемента используется метод `driver.findElement()`.

```kotlin
import io.appium.java_client.AppiumBy

// Найти элемент по ID
val usernameField = driver.findElement(AppiumBy.id("com.example.app:id/username_input"))

// Найти элемент по Accessibility ID
val loginButton = driver.findElement(AppiumBy.accessibilityId("login-button"))
```
