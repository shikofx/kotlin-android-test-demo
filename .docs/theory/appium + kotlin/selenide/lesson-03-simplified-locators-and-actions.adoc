== Лаконичный поиск элементов: `$` и `$$`

Selenide предоставляет две основные функции для поиска элементов, которые заменяют `driver.findElement` и `driver.findElements`.

*   **`$` (знак доллара):** Ищет *первый* элемент, соответствующий локатору. Возвращает объект `SelenideElement`.
*   **`$$` (два знака доллара):** Ищет *все* элементы, соответствующие локатору. Возвращает коллекцию `ElementsCollection`.

```kotlin
import com.codeborne.selenide.Selenide.`$`
import com.codeborne.selenide.Selenide.`$$`
import io.appium.java_client.AppiumBy

// Найти поле для ввода имени пользователя
val usernameField = `$`(AppiumBy.id("com.example.app:id/username_input"))

// Найти все кнопки на экране
val allButtons = `$$`(AppiumBy.className("android.widget.Button"))
```

== Взаимодействия со встроенными ожиданиями

Самое главное преимущество Selenide — **автоматические неявные ожидания (implicit waits)**. Когда вы вызываете действие, например `click()`, Selenide сначала дожидается, пока элемент станет видимым и кликабельным, и только потом выполняет действие.

Давайте перепишем наш тест на вход в систему.

```kotlin
import com.codeborne.selenide.Selenide.`$`
import io.appium.java_client.AppiumBy

@Test
fun successfulLogin_withSelenide() {
    `$`(AppiumBy.id("com.example.app:id/username_input")).sendKeys("standard_user")
    `$`(AppiumBy.id("com.example.app:id/password_input")).setValue("secret_sauce") // setValue - синоним sendKeys
    `$`(AppiumBy.id("com.example.app:id/login_button")).click()

    // Проверка будет в следующем уроке
}
```

В этом коде нет ни одного `WebDriverWait`. Если какой-то из элементов появится с задержкой, Selenide просто подождет его (по умолчанию до 4 секунд). Этот таймаут легко настраивается.
