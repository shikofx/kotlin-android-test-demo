Помимо простых кликов и ввода текста, Appium позволяет выполнять сложные жесты, такие как свайпы, масштабирование и т.д.

[[section-w3c-actions]]
== W3C Actions API

Современный способ выполнения жестов в Appium — это использование W3C Actions API. Он позволяет создавать цепочки действий для симуляции сложных прикосновений.

=== Пример: Свайп вниз для обновления (Pull-to-Refresh)

```kotlin
import org.openqa.selenium.interactions.PointerInput
import org.openqa.selenium.interactions.Sequence
import java.time.Duration

fun swipeDown() {
    // Получаем размеры экрана
    val size = driver.manage().window().size
    val startX = size.width / 2
    val startY = (size.height * 0.2).toInt() // Начало свайпа - 20% от верха экрана
    val endY = (size.height * 0.8).toInt()   // Конец свайпа - 80% от верха экрана

    // Создаем последовательность действий для одного "пальца"
    val finger = PointerInput(PointerInput.Kind.TOUCH, "finger")
    val swipe = Sequence(finger, 1)

    swipe.addAction(finger.createPointerMove(Duration.ofMillis(0), PointerInput.Origin.viewport(), startX, startY))
    swipe.addAction(finger.createPointerDown(PointerInput.MouseButton.LEFT.asArg()))
    swipe.addAction(finger.createPointerMove(Duration.ofMillis(700), PointerInput.Origin.viewport(), startX, endY))
    swipe.addAction(finger.createPointerUp(PointerInput.MouseButton.LEFT.asArg()))

    // Выполняем последовательность
    driver.perform(listOf(swipe))
}
```

[[section-touchaction-legacy]]
== `TouchAction` (Legacy)

В старых версиях Appium (и во многих примерах в интернете) вы можете встретить класс `TouchAction`. Он был заменен на W3C Actions и считается устаревшим, но все еще работает.

=== Пример: Свайп с помощью `TouchAction`

```kotlin
import io.appium.java_client.touch.offset.PointOption
import io.appium.java_client.TouchAction

fun swipeDownLegacy() {
    // ... расчет координат startX, startY, endY ...

    TouchAction(driver)
        .press(PointOption.point(startX, startY))
        .waitAction(WaitOptions.waitOptions(Duration.ofMillis(700)))
        .moveTo(PointOption.point(startX, endY))
        .release()
        .perform()
}
```

**Рекомендация:** Используйте новый W3C Actions API, так как он является текущим стандартом и более гибок.
