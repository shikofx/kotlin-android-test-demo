Для работы с Appium нам нужно настроить несколько компонентов.

[[section-appium-server]]
== 1. Установка Appium Server

Appium Server — это приложение на Node.js, которое принимает команды от ваших тестов.

*   **Установите Node.js и npm:** Если они еще не установлены, скачайте их с официального сайта nodejs.org.
*   **Установите Appium через npm:** Откройте терминал и выполните команду:
    `npm install -g appium`
*   **Установите драйвер UiAutomator2:** Appium использует драйверы для разных платформ. Для Android нам нужен UiAutomator2.
    `appium driver install uiautomator2`

[[section-appium-inspector]]
== 2. Установка Appium Inspector

**Appium Inspector** — это незаменимый инструмент. Это десктопное приложение, которое позволяет "инспектировать" UI вашего мобильного приложения: просматривать иерархию элементов, находить их атрибуты (ID, текст, accessibility ID) и даже записывать базовые действия.

Скачайте его с официальной страницы Appium на GitHub.

[[section-project-dependencies]]
== 3. Настройка зависимостей в проекте

В ваш `build.gradle.kts` нужно добавить клиентскую библиотеку Appium для Java/Kotlin.

```kotlin
// build.gradle.kts (app)

dependencies {
    // Appium Java Client
    testImplementation("io.appium:java-client:9.2.2") // Уточните последнюю версию

    // Selenium нужен для работы Appium клиента
    testImplementation("org.seleniumhq.selenium:selenium-java:4.15.0")
}
```

После выполнения этих шагов ваше окружение будет готово к написанию первого Appium-теста.
