== `insertProducts(List<ProductModel> list)`

=== Цель
Проверить, что ViewModel корректно делегирует задачу вставки в DAO и обновляет состояние UI.

[cols="1,3,3,3,2"]
|===
| ID | Сценарий | Входные данные | Ожидаемый результат | Тип теста

| *SVI-2* | Вставка списка продуктов | `List<ProductModel>` для вставки. | 1. `appDao.insertProduct()` вызывается с предоставленным списком. +
2. LiveData прогресс-бара (`pb`) обновляется на `View.GONE`. | Позитивный
|===
