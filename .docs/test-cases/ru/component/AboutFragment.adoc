[[about-fragment-test-cases]]
= Тест-кейсы для `AboutFragment`

*Эпик:* `UI-тестирование (Espresso)`
*Фича:* `Экран "О приложении"`

'''

== Отображение элементов экрана

*История:* `AF-STORY-1: Отображение базовой информации`
*Цель:* Убедиться, что все статические элементы UI (текст версии, ссылки) корректно отображаются при запуске экрана.
*Теги:* `espresso`, `component-ui`
*Шаги:*
. Запустить `AboutFragment` с помощью `FragmentScenario`.
*Ожидаемый результат:*
. На экране отображается текст с версией приложения (например, "V.1.0.0-build 1").
. На экране отображается текст для ссылки "https://saucelabs.com/".

'''

== Переход по веб-ссылкам

*История:* `AF-STORY-2: Взаимодействие со ссылками`
*Цель:* Проверить, что при клике на текстовую ссылку в рамках полного пользовательского сценария инициируется корректный `Intent` для открытия веб-браузера.
*Теги:* `espresso`, `integration-ui`
*Шаги:*
. Запустить приложение со `SplashActivity`, чтобы симулировать реальный пользовательский путь.
. Перейти на экран "О приложении".
. Кликнуть на текстовое поле `webTV`.
*Ожидаемый результат:*
. Перехвачен `Intent` с действием `Intent.ACTION_VIEW`.
. Данные (`data`) в `Intent` соответствуют URL "https://saucelabs.com/".
*Шаги (дополнительно):*
. Кликнуть на текстовое поле `versionTV`.
*Ожидаемый результат (дополнительно):*
. Перехвачен `Intent` с действием `Intent.ACTION_VIEW`.
. Данные (`data`) в `Intent` содержат URL, ведущий на страницу релизов на GitHub.

'''

== Обработка отсутствия браузера

*История:* `AF-STORY-2: Взаимодействие со ссылками`
*Цель:* Проверить, что приложение корректно обрабатывает ситуацию, когда на устройстве нет приложения для обработки `Intent.ACTION_VIEW` (например, нет браузера).
*Теги:* `espresso`, `integration-ui`
*Шаги:*
. Запустить `AboutFragment`.
. Настроить `Intents.init()` так, чтобы при попытке запуска `Intent` выбрасывалось исключение `ActivityNotFoundException`.
. Кликнуть на текстовое поле `webTV`.
*Ожидаемый результат:*
. На экране появляется `Toast`-сообщение с текстом "No application can handle this request...".
