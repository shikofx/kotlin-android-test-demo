[[login-fragment-test-cases]]
== LoginFragment Test Cases

=== Отображение элементов

* Цель: Убедиться, что все необходимые элементы UI отображаются на экране.
* Тег: `component-ui`
* Шаги:
.. Открыть `LoginFragment`.
* Ожидаемый результат:
.. Отображаются поля для ввода логина и пароля.
.. Отображается кнопка "Login".
.. Отображаются кнопки для выбора стандартных пользователей.
.. Отображаются все необходимые надписи и подсказки.

=== Валидация полей

* Цель: Проверить, что при попытке входа с пустыми полями отображаются сообщения об ошибках.
* Тег: `component-ui`
* Шаги:
.. Открыть `LoginFragment`.
.. Оставить поля логина и пароля пустыми.
.. Нажать кнопку "Login".
* Ожидаемый результат:
.. Отображаются сообщения об ошибках для обоих полей.

=== Автозаполнение полей

* Цель: Проверить, что при выборе стандартного пользователя поля логина и пароля заполняются автоматически.
* Тег: `component-ui`
* Шаги:
.. Открыть `LoginFragment`.
.. Нажать на кнопку выбора стандартного пользователя.
* Ожидаемый результат:
.. Поля логина и пароля заполняются соответствующими данными.

=== Успешная авторизация

* Цель: Проверить, что при вводе валидных данных происходит успешная авторизация и переход на следующий экран.
* Тег: `component-ui`
* Шаги:
.. Открыть `LoginFragment`.
.. Ввести валидные логин и пароль.
.. Нажать кнопку "Login".
* Ожидаемый результат:
.. Происходит переход на следующий экран (например, `ProductCatalogFragment`).

=== Отображение ошибки при неудачной авторизации

* Тег: `component-ui`
* Шаги:

* Ожидаемый результат:

* Цель: Проверить, что при попытке входа заблокированным пользователем отображается соответствующее сообщение.
* Тег: `component-ui`
* Шаги:

* Цель: Проверить, что при отсутствии сетевого соединения или при таймауте отображается соответствующее сообщение.

* Шаги:
